# Monomach.ru — режим эффективной работы

Рабочий стол WindowsFX в браузере: регистрация по имени и паролю, личный диск на сервере (по умолчанию 1 ГБ),
офисные программы (Lexicon, Tabs, Photostore), Проводник, Напоминания, Дела, Матрица времени и остальные программы.
Настройки, рабочий стол и данные программ сохраняются в учётной записи при каждом изменении —
можно войти с любого компьютера, и всё будет на месте.

## Возможности

- **Регистрация и вход** — имя и пароль (не короче 8 символов). Защита от подбора пароля и массовых регистраций.
- **Личный диск** D: на сервере с лимитом места; файлы с компьютера загружаются перетаскиванием или кнопкой «Загрузить».
- **Диски, которые пользователь подключает сам** (Проводник → «Этот компьютер» → «Подключить диск», или Параметры → «Учётная запись и диски»):
  - **Яндекс Диск** — логин Яндекса и пароль приложения (Яндекс ID → Безопасность → Пароли приложений → «Файлы»);
  - **Облако Mail.ru** — адрес почты и пароль для внешнего приложения с доступом «Облако / WebDAV»;
  - **Google Диск** — кнопка «Войти через Google» (нужна настройка, см. ниже);
  - **любой WebDAV** — Nextcloud, ownCloud, Synology, pCloud, 4shared и др.;
  - **папка компьютера** (Chrome, Edge, Яндекс Браузер, Opera) — файлы читаются и сохраняются прямо на компьютере пользователя и не загружаются на сервер; папка помнится в этом браузере.
  Облачные диски получают постоянные буквы (G:, H: …), папки компьютера — L:, M: … Пароли облаков хранятся на сервере в зашифрованном виде (AES-256-GCM).
- **Панель администратора** `/admin` (свой логин и пароль): пользователи, кто и когда входил (IP, браузер), неудачные попытки, занятое место,
  подключённые диски, блокировка, сброс пароля, лимит диска, удаление; журнал событий с фильтрами и выгрузкой в Excel (CSV); закрытие регистрации.

## Установка на сервер

Нужен VPS с Ubuntu 22.04/24.04 (1 ядро, 1–2 ГБ памяти; место на диске — по числу пользователей × лимит) и домен.

1. В панели регистратора домена создайте DNS-записи **A** для `monomach.ru` и `www.monomach.ru` с IP-адресом сервера.
2. Подключитесь к серверу по SSH под root и выполните:
   ```
   curl -fsSL https://raw.githubusercontent.com/Arthuralend/WindowsFX/main/web/deploy/install.sh | bash -s -- monomach.ru
   ```
   Скрипт установит Node.js 22 и Caddy (HTTPS-сертификат выпускается автоматически), скачает сайт и офисные программы,
   запустит службу `monomach` и выведет пароль администратора.
3. Откройте `https://monomach.ru/admin` и смените пароль администратора (раздел «Настройки»).

Обновление сайта — тот же скрипт ещё раз. Данные пользователей лежат в `/var/lib/monomach` (база `monomach.db` и папки дисков) —
их и стоит копировать в резервную копию.

Настройки — в файле `/etc/monomach.env` (после изменений `systemctl restart monomach`):

| Переменная | Что задаёт |
|---|---|
| `PUBLIC_URL` | адрес сайта, например `https://monomach.ru` (нужен для входа через Google) |
| `DEFAULT_QUOTA_MB` | лимит личного диска нового пользователя (по умолчанию 1024) |
| `ADMIN_LOGIN`, `ADMIN_PASSWORD` | администратор при первом запуске; `ADMIN_RESET=1` — сбросить пароль на указанный |
| `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET` | вход через Google для подключения Google Диска |
| `SITE_NAME` | название на сайте (по умолчанию Monomach) |

## Google Диск

1. Откройте [console.cloud.google.com](https://console.cloud.google.com), создайте проект.
2. «APIs & Services» → «Library» → включите **Google Drive API**.
3. «OAuth consent screen» → тип External, название Monomach, домен monomach.ru; в «Scopes» добавьте `.../auth/drive`;
   пока приложение не проверено Google, добавьте адреса пользователей в «Test users» (до 100 человек).
4. «Credentials» → «Create credentials» → «OAuth client ID» → тип **Web application**;
   в «Authorized redirect URIs» укажите `https://monomach.ru/api/cloud/google/callback`.
5. Скопируйте Client ID и Client secret в `/etc/monomach.env` и выполните `systemctl restart monomach`.

Для открытого доступа всем пользователям Google требует проверку приложения (полный доступ к Диску — «restricted scope»), она занимает от нескольких недель.

## Запуск для разработки

```
cd web
node server/index.js        # http://localhost:8080, данные в web/data
```
Node.js 22.13 или новее (встроенный SQLite). Сторонние пакеты не нужны.
