# WindowsFX — рабочий стол в стиле Windows для Android

WindowsFX превращает телефон или планшет в настольный компьютер: окна, панель задач, меню «Пуск» и встроенные программы. Интерфейс на русском и английском языках.

## Что есть в версии 0.1

- **Рабочий стол** со значками, обоями и контекстным меню.
- **Окна**: перемещение, изменение размера, свернуть / развернуть / закрыть, привязка к краям экрана (как Snap в Windows), двойное нажатие по заголовку разворачивает окно.
- **Панель задач** по центру: «Пуск», поиск, закреплённые программы, открытые окна, переключатель языка RU / ENG, Wi-Fi, батарея, часы.
- **Меню «Пуск»** со всеми программами и Android-приложениями, поиском, закреплением на панели задач и рабочем столе.
- **Проводник**: «Этот компьютер», внутренняя память и SD-карты, быстрый доступ, копирование, вырезание, вставка, переименование, удаление, свойства, сортировка, скрытые файлы.
- **Блокнот**, **Paint**, **Просмотр PDF**, **Калькулятор**.
- **Параметры**: обои, тёмная / светлая тема, масштаб интерфейса, язык, оконный режим, быстрый доступ к системным настройкам.
- **Android-приложения в окнах** на устройствах, где включён оконный режим (freeform).
- Адаптация под любое разрешение экрана.

## Как установить

1. Откройте вкладку **Releases** этого репозитория.
2. Скачайте последний файл `WindowsFX-*.apk` на устройство и установите его.
3. Нажмите кнопку «Домой» и выберите WindowsFX как рабочий стол по умолчанию.

Каждый новый APK ставится поверх предыдущего без удаления.

## Сборка

APK собирается автоматически через GitHub Actions при каждом изменении в ветке `main` (см. `.github/workflows/build.yml`).
Локально: `gradle :app:assembleRelease` (JDK 17, Android SDK 35).
